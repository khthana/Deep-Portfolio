## Use Case

### U-001 — ดูงานทั้งหมด

ผู้เรียนสามารถดูรายการงานทั้งหมดที่ได้รับมอบหมายจากทุกรายวิชาที่ลงทะเบียนเรียนในรูปแบบรายการ เรียงตามวันกำหนดส่ง

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน |
| Post-Condition | ระบบแสดงรายการงานทั้งหมดที่ผู้เรียนต้องทำ |

### U-002 — ดูรายละเอียดงาน

ผู้เรียนสามารถเลือกดูรายละเอียดของงานแต่ละชิ้น ซึ่งรวมถึงคำสั่ง รูปแบบการส่ง วันกำหนดส่ง และไฟล์แนบที่เกี่ยวข้อง

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน และเลือกงานจากรายการ |
| Post-Condition | ระบบแสดงรายละเอียดของงานที่เลือกอย่างครบถ้วน |

### U-003 — ส่งงานในรายวิชา

ผู้เรียนสามารถอัปโหลดไฟล์งานเพื่อส่งสำหรับงานในรายวิชา

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน |
| Post-Condition | ผู้เรียนส่งงานสำเร็จ และได้รับการบันทึกการส่งงานในระบบ |

### U-004 — จัดการกลุ่มทำงาน

ผู้เรียนสามารถสร้าง แก้ไข กลุ่มทำงานสำหรับงานกลุ่มที่ได้รับมอบหมาย

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน และมีงานกลุ่มที่ต้องการจัดทำ |
| Post-Condition | ผู้เรียนสามารถสร้างหรือจัดการสมาชิกในกลุ่มทำงานได้สำเร็จ |

### U-005 — ดูข้อมูลรายวิชา

ผู้เรียนสามารถเข้าถึงข้อมูลที่เกี่ยวข้องกับรายวิชา ซึ่งครอบคลุมถึงการ ดูรายวิชาที่ลงทะเบียนไว้ ดูรายละเอียดรายวิชา การดาวน์โหลดสื่อการสอนในรายวิชา การดูประกาศในรายวิชา และการดูผลประเมินในรายวิชา

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน |
| Post-Condition | ระบบแสดงข้อมูลรายวิชาและผลการประเมินที่ผู้เรียนต้องการเข้าถึง |

### U-006 — ดูการกำหนดการเรียน/กิจกรรม

ผู้เรียนสามารถตรวจสอบตารางเวลา กิจกรรมการเรียนรู้ กิจกรรมการเรียนรู้ทั้งหมดที่ผู้สอนได้กำหนดไว้ในทุกรายวิชา และรวมถึงกิจกรรมการศึกษา ในรูปแบบปฎิทิน

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน |
| Post-Condition | ระบบแสดงกำหนดการเรียนและกิจกรรมทั้งหมด |

### U-007 — จัดการข้อมูลส่วนตัว

ผู้เรียนสามารถแก้ไขข้อมูลส่วนตัวในระบบ ซึ่งรวมถึงการจัดการข้อมูลการศึกษาและการอบรม การจัดการข้อมูลประสบการณ์และทักษะ และการจัดการข้อมูลกิจกรรมและการแข่งขัน

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน |
| Post-Condition | ข้อมูลส่วนตัวและข้อมูลประวัติของผู้เรียนได้รับการแก้ไข/บันทึกสำเร็จ |

### U-008 — สร้าง portfolio

ผู้เรียนสามารถรวบรวมและจัดเรียงผลงาน หรือกิจกรรมที่ทำในระบบ รวมถึงข้อมูลส่วนตัวที่มี เพื่อสร้างเป็นแฟ้มสะสมผลงาน (Portfolio) ส่วนตัว

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้เรียน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้เรียน และมีข้อมูลผลงาน/กิจกรรมที่พร้อมใช้งาน |
| Post-Condition | ผู้เรียนสร้างและบันทึกแฟ้มสะสมผลงานได้สำเร็จ |

### U-009 — จัดการประกาศ

ผู้สอนสามารถสร้าง แก้ไข หรือลบประกาศสำคัญในรายวิชาเพื่อสื่อสารข้อมูลและข่าวสารให้ผู้เรียนทราบ

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้สอน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้สอน |
| Post-Condition | การจัดการประกาศ (สร้าง/แก้ไข/ลบ) ในรายวิชาสำเร็จ |

### U-010 — จัดการรายวิชา

ผู้สอนสามารถสร้าง ปรับปรุง แก้ไข หรือจัดโครงสร้างเนื้อหาของรายวิชาที่รับผิดชอบ ซึ่งรวมถึงการจัดการรายละเอียดรายวิชา การจัดการแผนการสอน การวางแผนรายวิชา และการจัดการสื่อการสอน

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้สอน |
| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้สอน |
| Post-Condition | ผู้เรียนการจัดการข้อมูล โครงสร้าง และสื่อการสอนของรายวิชาสำเร็จ |

### U-011 — จัดการงานและกิจกรรม

ผู้สอนสามารถสร้างกิจกรรมการประเมินและกิจกรรมการเรียนรู้

| หัวข้อ | รายละเอียด |
| --- | --- |
| Actor | ผู้สอน |

### U-012 — ประเมินงานผู้เรียน

ผู้สอนสามารถตรวจทานงานและ ให้คะแนนที่ผู้เรียนส่งมาในระบบ

| หัวข้อ | รายละเอียด |

| Post-Condition | ผู้เรียนผู้สอนประเมินและบันทึกคะแนนงานของผู้เรียนสำเร็จ |

### U-013 — ดูคะแนนโดยรวมรายวิชา/กิจกรรม/บุคคล

ผู้สอนสามารถเรียกดูสรุปผลคะแนนรวมของรายวิชา รายกิจกรรม หรือรายบุคคล

| หัวข้อ | รายละเอียด |

| Pre-Condition | ต้องเข้าสู่ระบบในฐานะผู้สอน |
| Post-Condition | การเพิ่ม/ถอน รายชื่อผู้เรียนในรายวิชาสำเร็จ |
