# กรณีทดสอบจากเอกสาร (TC-01 – TC-75)

สกัดจากเอกสารปริญญานิพนธ์ `CE68-21 DEEP-Portfolio.docx` บทที่ 4 "ผลการทดลอง" (ตาราง 4.1–4.75) ตัวเอกสารต้นฉบับถูกนำออกจากเครื่องแล้วตาม D12 ใน [spec](./spec-refactor-redeploy.md)

> ใช้เป็น **checklist ความครอบคลุม** ของชุดทดสอบอัตโนมัติที่จะเขียน (T5 ในสเปก) ไม่ใช่สเปกของ test ที่ต้องเขียนตามตัวอักษร — TC เหล่านี้เป็นการทดสอบด้วยมือผ่าน UI ส่วนชุดทดสอบใหม่จับที่ HTTP boundary (T2) หนึ่ง TC จึงอาจกลายเป็นหลาย test หรือทดสอบไม่ได้เลยถ้าเป็นเรื่อง UI ล้วน

ผลทั้งหมดในเอกสารคือ PASS ซึ่งเป็นผลการทดสอบด้วยมือ ณ เวลาส่งงาน ไม่ใช่หลักประกันว่าโค้ดวันนี้ยังทำงานได้
